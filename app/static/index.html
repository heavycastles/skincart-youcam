From one selfie to a basket that fits your skin.

SkinCart scores 12 skin concerns with YouCam AI Skin Analysis, builds a routine from the shop's own catalog, and lets customers try on makeup before they order — on the web or in Telegram.

Photos are sent only to the YouCam API for analysis. Results are cached per image, so a re-scan costs nothing.

How it works

1 · Upload

YouCam File API stores the selfie once; every task reuses the same file id.

2 · Analyze

Skin Analysis scores 12 concerns and returns overlay masks.

3 · Match

Need-weighted matcher picks one product per step from the catalog.

4 · Try & order

Makeup VTO renders shades; the order becomes a scored lead.
